# Titanic Missing Value Identification

## Project Overview
This project identifies missing values in the Titanic dataset using Python and Pandas in Google Colab. It helps understand data quality before cleaning and analysis.

## Objectives
- Load the Titanic dataset.
- Identify missing values in each column.
- Calculate the percentage of missing values.
- Identify columns that require data cleaning.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- GitHub

## Steps Performed
1. Loaded the Titanic dataset into a Pandas DataFrame.
2. Inspected the dataset and its columns.
3. Used `isnull().sum()` to count missing values.
4. Calculated missing-value percentages.
5. Generated a report of columns containing missing values.

## Files
- `Titanic_Missing_Values.ipynb` – Google Colab notebook containing the code and output.

## Results
The notebook displays the number and percentage of missing values in each affected column. This report helps decide how to handle missing data before further analysis.
